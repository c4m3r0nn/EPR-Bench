**FIX FIRST.** Eight findings, ranked by severity:

1. **P1 — The test guard is bypassable.** [conftest.py:82](tests/conftest.py:82). With process creation mocked, it allowed `shell=True` with `"claude -p hello"`, `["sh","-c","codex exec hello"]`, and bytes argv. Any `--version` argument exempts the entire command. `os.exec*` is untouched; asyncio shell calls inherit the shell bypass. The fixture also starts after test-module imports. **Fix:** install protection before collection, cover exec/spawn and child processes, reject uncontrolled shells/wrappers, and allow only exact help/version invocations of real CLIs.

2. **P1 — One tool call can defeat timeout and action accounting.** [claude_browser.py:246](src/eprbench/agents/claude_browser.py:246), [cli_browser.py:329](src/eprbench/agents/cli_browser.py:329). `key.repeat` is unbounded and executes synchronously after one charge. A mocked three-press call exceeded a 0.5-second deadline, continued after submission, and returned OK with `stop=None`. Huge repeats can prevent the harness from reaching process termination. Submission also makes the outer loop skip timeout checking. **Fix:** bound arguments, check deadline/submission between primitive actions, and enforce a deadline independently of the browser execution loop.

3. **P1 — Claude’s paired arms receive different instruction environments.** [cli_browser.py:133](src/eprbench/agents/cli_browser.py:133). API uses `--safe-mode`; UI cannot, and explicitly retains plugins and user `CLAUDE.md`. A home instruction can change clinical behaviour only in the UI arm, or introduce benchmark knowledge. **Fix:** use a controlled, identical instruction/configuration environment for both arms and record the effective instructions/tool inventory. Sharing `SYSTEM_PROMPT` does not establish parity.

4. **P1 — Cancelled potassium prescriptions game the new window.** [preview-hypok-judgement.json:35](src/eprbench/data/tasks/preview-hypok-judgement.json:35). Reproduced in memory: replacement prescribed at 11:30 with repeat U&E at 16:00 fails; adding a 09:30 prescription immediately stopped without administration makes the same treatment/recheck pass, with no near miss. The minimum includes stopped prescriptions and does not require qualifying replacement. **Fix:** anchor to the qualifying treatment episode, excluding cancelled, never-administered prescriptions. Specify a consistent fallback before the first administered dose.

5. **P2 — Resume permits product/model drift within pairs.** [runner.py:210](src/eprbench/runner.py:210). CLI versions are recorded but never validated; changing the mocked version produced no pin changes. CLI harnesses put observed models in `agent_config`, while resume checks `reported_models`, which remains empty. Default-model pairs can silently span an upgrade. **Fix:** validate CLI versions and requested model/effort, compare observed models where available, and key tracking by agent product as well as model.

6. **P2 — Final chance can erase an answer and charges screenshots differently.** [cli_browser.py:285](src/eprbench/agents/cli_browser.py:285), [cli_browser.py:349](src/eprbench/agents/cli_browser.py:349). Reaching a limit while filling `/reply` reloads it, losing the draft. Every subsequent call—including screenshots—consumes the 40-action allowance, unlike ordinary screenshot accounting. API submission remains uncharged. **Fix:** preserve drafts, separate screenshot and interaction allowances, and explicitly define comparable submission opportunity.

7. **P2 — Bridge shutdown leaves outstanding workers blocked.** [cli_browser.py:231](src/eprbench/agents/cli_browser.py:231). A socketpair probe reproduced a worker surviving `close()` and peer closure after the harness dequeued its message: it waits forever on `box.get()`. A handler failure, such as the unguarded final-chance screenshot failing, takes this path. **Fix:** track and release all outstanding boxes and connections; shut down sockets and join workers.

8. **P2 — Redaction can corrupt screenshot evidence.** [episode.py:170](src/eprbench/episode.py:170), [cli_agent.py:205](src/eprbench/agents/cli_agent.py:205). A valid base64 string containing a credential-pattern match became `[REDACTED]`. **Fix:** parse structured events and exempt image payloads from textual pattern substitution. The supplied smoke is unaffected: all nine stdout images match saved PNGs, and its manifest validates.

I found no demonstrated cookie/DOM escape through the relay or MCP resource listing: the relay contains no cookie, and unsupported resource methods are rejected. Cookie refusal precedes application access. However, Codex’s residual tools and writable scratch under the outer sandbox mean “only computer tools” is too strong; this review does not establish an adversarial isolation proof.

Counterbalancing produced 40 episodes with five starts per interface per product. Shared answer schemas, patient checks, and launch-time clocks are sound foundations. Viewport scrolling, screenshot latency, native-resolution zoom, two-step confirmation, and differing action units remain experimental differences requiring disclosure.

All probes used the specified Python/environment; no files, remotes, paid APIs, or real agent CLIs were used. In-memory grading and socketpair probes ran; Chromium/end-to-end tests were not run under the read-only filesystem.
