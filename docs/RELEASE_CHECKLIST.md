# Before the repository is made public

Everything below must be true, and ticked by the owner, before the repository (or a copy of it) is published.
Nothing here has been published or decided on the owner's behalf. `uv run python scripts/release_scan.py` checks the
tracked tree for the mechanical items (credential-like strings, quoted or not; absolute home-directory paths; email
addresses; NHS numbers outside the 999 test range; environment files by any name, `.env`, `.env.local`,
`.envproduction`, `prod.env`; task and bundle files without the canary; `LICENSE`, `LICENSE-CONTENT.md`, `NOTICE` and
`CITATION.cff` missing from the tracked tree) and lists every finding not on its allowlist as `file:line`. The allowlist,
`scripts/release_scan_allow.json`, names each deliberate test fixture with its reason. Untracked files are not
scanned. The section below is regenerated from a fresh scan (`--write-checklist`), and a test holds it to the scan.
